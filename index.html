About Iberian Script

The Iberian script was used on the Iberian Peninsula in ancient times. It's a semi-syllabic writing system where consonant+vowel combinations are represented by single symbols.

Usage Tips
  • Iberian script is semi-syllabic: "ka", "ke", "ki" etc. are single symbols
  • Letters c, g → k-series; d → t-series; p, v → b-series
  • Type "rr" for the special trilled R symbol
